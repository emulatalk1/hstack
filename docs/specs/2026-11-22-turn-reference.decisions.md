# Decisions of the builder: spec 4, the stop hook judges a turn by what changed in it

## Entry points

- `hooks/hooks.json`: a third entry, `UserPromptSubmit`, whose command is `bun "${CLAUDE_PLUGIN_ROOT}/scripts/hstack.ts" hook-prompt`. Claude Code runs it when a message is sent (also for a message of another session, a report of a background agent and a scheduled task: the hooks reference).
- `scripts/hstack.ts hook-prompt` (new verb, "the prompt hook"): reads the hook's JSON on stdin, goes to `CLAUDE_PROJECT_DIR` (or the current folder), follows `.hstack/repo` as the other two hooks do, and writes the turn's note, the state file `turn` (the repository's fingerprint when the turn started), when no note is there. It prints nothing and exits 0, whatever happens.
- `scripts/hstack.ts hook-start`: takes the session's reference (`session-head`) when the state folder holds none, whatever the source; and ends a turn left open (removes `turn`) at `startup` only (E2).
- `scripts/hstack.ts hook-stop`: compares with the turn's note when there is one, else with `session-head`; lets a turn end after a finished run of this session when the note says nothing changed; removes the note on every way out that lets the turn end as clean (not at the cap, and at a feedback pass only when nothing changed: E1, E8); prints "Decide from the approved spec and the code." only when the run's spec is approved.
- `scripts/hstack.ts spec --drop` and `repo <path>`: both already set `session-head` in the middle of a turn; each now also takes the turn's note again, so that the turn stays open (below, E11 and E12).
- `scripts/hstack.ts` with no verb or an unknown one: the usage line names `hook-prompt`.
- The state folder: one new file, `turn`. It stays when `start` or `spec --drop` moves a run to `old/` (E13).
- Texts: `skills/brainstorm/SKILL.md` (the fourth point of "In hstack", the paragraph "Spike to feel things out"), `README.md` (the status paragraph, the paragraph on `bun` not on the `PATH`, the row `hooks/` of the folder table), `.claude-plugin/plugin.json` (the version).
