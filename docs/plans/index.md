# Plans

* [hstack foundation plan](2026-10-26-hstack-foundation.md) - The plugin skeleton, init, the manifest, the OKF checker and the safety checks every later hstack step calls.
* [Bun runtime plan](2026-10-26-bun-runtime.md) - Move hstack's scripts, tests and skills from Node to Bun, using Bun's own APIs wherever Bun has one.
* [Own services plan (stack A)](2026-10-27-own-services.md) - Superseded, never built. init gives a stack A project its own Postgres and Mailpit in a named compose file, assigns their ports and writes the ports into the app's .env.
* [Measuring stick: pre-registration plan (Part 1)](2026-10-27-benchmark-prereg.md) - Hypotheses, task set, oracle, validation, task and run counts, cost and acceptance thresholds of the benchmark that measures the hstack harness, registered before any run.
* [Benchmark tools plan](2026-10-27-bench-tools.md) - Step 2 of the benchmark pre-registration: the throwaway environment, the oracle grader, the bug replay for test and agent layers, and the arm runner with its fixed responder.
* [Benchmark inputs and replay readiness plan](2026-10-27-bench-inputs.md) - Prereg step 3a (filtered input, filter log and interface sheet of every real-estate task, each by a sealed agent) and the three gaps to close before the sealed replays of step 3.
* [Held-out set and layer replay plan](2026-10-27-bench-replay.md) - Prereg step 3: sweep framework identifiers out of the inputs, extend the held-out set by a sealed agent, replay the existing layers on the dev and held-out sets, and lock the result.
* [External task selection plan](2026-11-02-bench-external.md) - Prereg step 4: register the rulings section 4.2 leaves open, enumerate and sort the external candidates once, walk the list in order checking each task in a container, and lock 24 tasks.
* [Oracle preparation plan](2026-11-03-bench-oracles.md) - Prereg step 5: check that each external web or desktop task can be served in a container, then label the oracle sources, rewrite their tests as black-box checks, write the missing interface sheets, validate every check and classify it twice.
* [Step oracle plan](2026-11-05-bench-step-oracles.md) - Prereg step 6: reclassify p8b with its interface sheet, record the H1 floor-rule decision with its numbers, and build the step oracle every task's H1 build score then comes from, with the one scoring rule later steps reuse.
* [Seeded bugs plan](2026-11-05-bench-seeded-bugs.md) - Prereg step 7: seed single-hunk bugs at edges on the reference of every external task and of nine real-estate tasks, each with a black-box check validated to fail on the bug and pass on the reference, sealed like the held-out set, with the rules for how the oracles, section 8.4 and H5 read them.
* [Stick canary plan](2026-11-06-bench-canary.md) - Prereg step 8: replace run-arm's two shortcuts with a Docker box an arm cannot leave, settle the score d and arms.json, run B against B- on the 6 canary tasks with k = 2, and record the verdict with B's cost and spread.
* [Human steps plan](2026-11-08-bench-human-steps.md) - Prereg step 9: the human reads of sections 5, 6.3, 7.1, 7.2 and 9.3 through a local page that writes the answers to data files, the second batch of source pairs the human calls fix, the rule (b) recount, and the step 8 carry-overs, locked with the list of what step 10 must hash again.
* [Stick v1 plan](2026-11-08-bench-stick-v1.md) - Prereg step 10: rerun the external step oracles and the kills that step 9's changes made stale, commit the task lists, hash every file of the stick into one manifest, compare it with the step 3 to step 9 locks with a reason for each changed file, and lock stick v1 as not validated.
